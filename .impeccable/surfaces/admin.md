# Admin and LMS MVP

- Route: `/admin` and `/admin/courses/*`
- Mode: Operate — help administrators maintain courses, lessons, and student access.
- Audience: Glew Studio administrators and course operators.
- Priority: real course and student records, then course/module/lesson authoring and secure playback.
- Visual constraints: inherit Glewstudio's Manrope typography, OLED `#0A0A0F` background, and restrained `#E8B86D` accent.
- Interaction constraints: server-authorized admin actions, explicit loading/error/empty states, responsive tables, and no demo metrics or hard-coded credentials.
